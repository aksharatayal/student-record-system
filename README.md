# Student Record System - Java

A clean Java project for managing student records, built for Google STEP prep.

### What it demonstrates?
This is not a basic print program. It covers what STEP interviewers look for in 1st year:
- **OOPs Concepts:** Classes & Objects (StudentInfo class)
- **Data Structures:** ArrayList for dynamic student storage
- **Clean Code:** Separation of data (StudentInfo) and logic (StudentRecordSystem)

### Features
- Stores Roll No, Full Name, Department
- Add students dynamically
- Display all records with formatted output

### Tech Stack
Java, ArrayList, OOPs

### How to Run
javac StudentRecordSystem.java
java StudentRecordSystem
